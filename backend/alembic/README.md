# Alembic Migrations

InsightBank-AI now targets PostgreSQL.

## Apply Migrations

```powershell
cd backend
$env:DATABASE_URL="postgresql+psycopg://insightbank:password@localhost:5432/bank_analyzer"
alembic upgrade head
```

## Create a New Migration

```powershell
cd backend
alembic revision --autogenerate -m "Describe your change"
```

Review autogenerated migrations before applying them. Keep migrations PostgreSQL-compatible and avoid importing `sqlalchemy.dialects.mysql`.

## Baseline

`versions/20260503_0001_postgresql_baseline.py` is the clean PostgreSQL baseline for the current schema.
